# Rive
- NEVER guess Rive syntax. Use `rive docs`, `rive docs gotchas`, `rive docs --search <term>`, `rive schema <Type>`.
- Rive is the source of truth for animation behavior that belongs in Rive. Use State Machines for interaction states.
- Do not duplicate Rive animation logic in React/CSS.
- Document every State Machine name and input in docs/rive-contract.md.
- Run `rive <project> --verify` after every RML change. Use --screenshot as evidence.

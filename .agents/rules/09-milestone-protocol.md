# Milestone protocol
SPEC -> PLAN -> IMPLEMENT -> TEST -> BROWSER VERIFY -> REVIEW -> COMMIT -> STOP.
- Never implement the whole project in one pass. Do only the current milestone (M01..M12).
- Before coding: read docs + all rules, list files you will change, explain approach briefly.
- Do not invent requirements, touch unrelated files, add dependencies without a documented reason, or start the next milestone.
- Human art direction is final authority. Report evidence (commands + screenshots), then wait.
